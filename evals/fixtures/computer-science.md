# Algorithms and Data Structures

Binary search requires a sorted sequence. It compares the target with the middle element and discards half of the remaining search interval after each comparison, giving logarithmic time complexity.

A hash collision occurs when distinct keys map to the same table position. Separate chaining stores colliding entries in a bucket, while open addressing probes for another available position.

Breadth-first search uses a queue and discovers vertices in increasing distance from the start. In an unweighted graph, this property allows it to recover a shortest path.

A recursive function needs a base case that stops further calls. Without a reachable base case, recursion continues until the runtime exhausts the call stack.
